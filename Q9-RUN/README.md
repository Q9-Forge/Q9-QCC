# Q9-RUN – Q9-Stack-IR-Interpreter

Interpreter `qrun` für den gemeinsamen Q9 Stack-IR. In der ersten Stufe wird
Text-IR direkt eingelesen; ein ausführbares P-Modul ist später vorgesehen.

```text
*.ir -> qrun -> Ausführung
```

Der bestehende Quellbestand wird aus dem eigenständigen Repository `Q9-Run`
mit erhaltener Historie übernommen.
