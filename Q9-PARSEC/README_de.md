# Q9-Parsec

[English](README.md)

Q9-Parsec ist ein EBNF-Parser- und Scanner-Generator. Er liest eine Grammatik
und erzeugt Parserquelltext, darunter eine C-Referenzimplementierung und
68k-Assembler. Der Q9-QCC-Bestand enthält diese Komponente neben dem Compiler,
der generierten Parserquelltext verwendet.

Folgende Anleitungen sind vorhanden:

- [Benutzerhandbuch](docs/BENUTZERHANDBUCH.md)
- [Entwicklerhandbuch](docs/ENTWICKLERHANDBUCH.md)
- [Architektur](docs/ARCHITEKTUR.md)
- [Dokumentationsübersicht](docs/README.md)
