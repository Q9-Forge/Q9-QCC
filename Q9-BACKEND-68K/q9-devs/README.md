# q9-devs – Q9-Device-Definitionen

Dieses Teilprojekt nimmt die gemeinsamen und architekturabhängigen Device-
Header und -Definitionen auf. Der vorhandene Bestand wird später aus
`Q9-Tools/System/devs` mit erhaltener Historie bzw. nachvollziehbarer Herkunft
übernommen.

```text
q9-devs/
├── DEFS/
│   └── Q9/
│       ├── devs/
│       ├── 68k/
│       └── x86/
├── src/
├── tests/
└── docs/
```
